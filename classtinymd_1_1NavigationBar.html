Detailed Description

template<typename RGB_T = TINYMD_DEFAULT_RGB_T>
class tinymd::NavigationBar< RGB_T >

Bottom navigation bar: 3-5 exclusive destinations, each an icon with a label underneath and a pill highlight behind the selected icon.

Register with Screen::addFixedWidget() so it stays pinned to the bottom of the viewport while scrollable content behind it scrolls.
