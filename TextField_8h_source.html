13/**
14 * @brief Single-line text input box.
15 *
16 * TextField only holds and displays text and focus state - it has no idea
17 * how to turn touches into characters. Pair it with a Keyboard (Keyboard.h):
18 *
19 * Keyboard<RGB565> keyboard(Bounds(0, 420, 340, 190));
20 * TextField<RGB565> nameField(Bounds(16, 88, 220, 48), "Name");
21 * keyboard.manage(nameField); // wires nameField's focus to this keyboard
22 * screen.addWidget(nameField);
23 * screen.addWidget(keyboard); // add last so it draws on top when shown
24 *
25 * insertChar()/backspace()/handleEnter() (TextInputTarget, see Core/
26 * TextInputTarget.h) are what let a Keyboard - or any other input source -
27 * drive a focused field without TextField needing to know about it. Enter
28 * submits (see TextArea.h for the multi-line counterpart, where Enter
29 * inserts a newline instead).
30 *
31 * Bounds is split internally into a small label strip (top) and the input
32 * box itself (the rest) - both are part of this widget's own bounds, so a
33 * tap anywhere in either area focuses the field.
34 *
35 * Known limitation: text longer than the box is drawn past its right edge
36 * rather than scrolling/clipping - TinyGPU's fonts have no sub-rect clip,
37 * only surface-edge clipping. Fine for short inputs (names, search terms,
38 * ...); not meant for long free-form text.
39 */
