Detailed Description

template<typename RGB_T = TINYMD_DEFAULT_RGB_T>
class tinymd::LineChart< RGB_T >

Line chart with one or more series, a vertical value scale with round-numbered grid lines, optional reference lines, and an optional card frame with a title and a footer line.

LineChart<RGB565> chart(Bounds(8, 8, 224, 140), "Temperature"); int s = chart.addSeries(colorFromHex<RGB565>(0x06B6D4)); chart.addReferenceLine(25.0f, colorFromHex<RGB565>(0xF59E0B)); chart.setValues(s, readings); // std::vector<float> screen.invalidate(); // data changed outside a gesture

Y axis: automatic (the range of all visible values, snapped outward to a 1/2/5 x 10^n step - see setGridCount()) or fixed via setYRange(); the grid values can also be given explicitly via setGridValues().

X axis: by default the points of each series are stretched over the full plot width. setVisiblePoints(n) instead gives every point a fixed spacing of width / (n - 1) with the newest point at the right edge - a rolling "oscilloscope" trace that scrolls in from the right as points are added.

Series with more points than the plot has pixel columns are drawn as a min/max envelope per column, so peaks are never lost however many points there are. All drawing goes through clipped primitives, so the chart works inside a scrolling Container.
