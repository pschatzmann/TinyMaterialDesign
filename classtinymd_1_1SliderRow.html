Detailed Description

template<typename RGB_T = TINYMD_DEFAULT_RGB_T>
class tinymd::SliderRow< RGB_T >

Caption and formatted value on one line, a Slider below. The value is quantized to step:

SliderRow<RGB565> gain("Gain", 0, 40, 1, [](float v, char* b, size_t n) { snprintf(b, n, "%+.0f dB", v); }); gain.onChange = [](float v) { ... };

Whether a drag starting at (x, y) - this widget's own coordinate space - should be classified as GestureType::kDrag. Default: just isDraggable(), ignoring the point - correct for any leaf widget. A composite (Container, Dialog, Drawer, Menu, BottomSheet) overrides this to recurse into whichever child sits at that point instead, so e.g. a Slider nested inside one of them is still recognized correctly by Screen::isDraggableAt().
