Detailed Description

template<typename RGB_T>
class tinymd::OffsetSurface< RGB_T >

Draws into target moved up by dy pixels, only inside the rows [clipTop, clipBottom) of target.

TinyGPU's drawing primitives take unsigned coordinates, and toPx() clamps negative values to 0: a widget whose top is above the edge of the surface (e.g. scrolled up in a Container) would be drawn at y = 0 with its full height instead of partly hidden. Container draws such a widget through an OffsetSurface: the widget is moved down by dy (so all its coordinates are >= 0) and every pixel is written dy rows higher, where it belongs. Pixel by pixel (via SurfaceBase), so only used for those widgets.
