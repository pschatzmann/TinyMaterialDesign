Detailed Description

template<typename RGB_T = TINYMD_DEFAULT_RGB_T>
class tinymd::FileDialog< RGB_T >

Open file dialog: browse folders and choose a file.

The dialog does not read the file system itself. The application supplies listDirectory(), which returns the entries of a folder, so the same dialog works with SD cards, flash file systems and the desktop.

The dialog is a panel (panel()) to show with Screen::presentDialog(). It lists the folders first, then the files whose extension is in the filter (all files if the filter is empty). A row "..", shown below the root, goes to the parent folder. Tapping a file calls onSelect(path); the application should dismiss the dialog then. Tapping Cancel calls onCancel (if set) and the dialog stays open unless the application dismisses it.

FileDialog<RGB565> dialog;
dialog.listDirectory = [](const std::string& dir) { ... SD entries ... };
dialog.onSelect = [&](const std::string& path) { screen.dismissDialog(); open(path); };
dialog.open(Bounds(8, 8, 224, 304), "Open book", "/", ".mobi,.azw,.azw3");
screen.presentDialog(dialog.panel());
