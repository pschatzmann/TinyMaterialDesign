Detailed Description

template<typename RGB_T = TINYMD_DEFAULT_RGB_T>
class tinymd::TextBlock< RGB_T >

Multi-line text that is wrapped at word boundaries to the widget width ('
' starts a new line) - for notes, explanations and messages. Unlike Label it can span several lines; heightFor() tells how much room the text needs, so a layout can size the widget to its text:

TextBlock<RGB565> note(Bounds(8, y, 224, 0), "A long explanation ..."); page.addChild(note); // gives it the theme note.bounds.h = note.heightFor(note.bounds.w);

Default: label font, onSurfaceVariant color, drawn on the page background.
