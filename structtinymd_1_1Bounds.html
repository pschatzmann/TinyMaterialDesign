Detailed Description

Axis-aligned pixel rectangle used for widget bounds and hit-testing.

Deliberately signed (unlike TinyGPU's size_t-based drawing calls) so widget layout math (x - radius, centering, ...) can't silently underflow; clamp to >=0 only at the point of calling into ISurface.
