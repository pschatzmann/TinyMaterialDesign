Detailed Description

template<typename RGB_T = TINYMD_DEFAULT_RGB_T>
class tinymd::IconButton< RGB_T >

Circular tap target hosting one vector glyph from Draw/Icons.h (or any function matching IconPainter). Tap feedback is a ripple, same rationale as Button (see Button.h's class comment).

◆ update()

bool update ( uint32_t  nowMs)
inlineoverridevirtual

Called once per frame, before draw(), to advance any time-based animation (ripple fade, indeterminate progress sweep, ...). Returns true if that advance changed anything this widget will draw differently, so Screen can decide whether a redraw is actually needed - see Screen::isDirty(). Default: no-op, not dirty, so widgets that don't animate cost nothing extra.
