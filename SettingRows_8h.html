Detailed Description

Rows for settings and detail pages: a caption combined with a control or a value. Each row is one widget, so a page only places rows from top to bottom. By default they are drawn on the page background; call setOnSurface(true) for rows inside a Card.

  • SliderRow: caption and formatted value, a Slider below (kHeight 40)
  • SwitchRow: caption, Switch at the right; tapping the row toggles it
  • RadioRow: RadioButton and caption; tapping the row selects it
  • KeyValueRow: key at the left, value at the right
