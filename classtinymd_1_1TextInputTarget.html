virtual bool handleEnter ( )

Called when the keyboard's Done key is tapped (a separate Enter key handles literal newlines via insertChar('
') directly, without going through this).

Returns
true if the keyboard should hide itself afterward - both TextField and TextArea return true here, since Done always means "finished editing", but the interface leaves room for a future field that wants Done to keep editing open instead.
