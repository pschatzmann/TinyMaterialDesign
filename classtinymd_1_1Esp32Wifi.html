Detailed Description

WifiControl for the ESP32: asynchronous scan and connection, the credentials are stored in the flash (Preferences, namespace "wifi") when a connection works, and used by begin().

Esp32Wifi wifi; void setup() { wifi.begin(); // connects with the stored credentials loginPage.setWifi(&wifi); }
