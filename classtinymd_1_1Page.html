Detailed Description

template<typename RGB_T = TINYMD_DEFAULT_RGB_T>
class tinymd::Page< RGB_T >

One page (tab) of an app: a scrollable Container with a title and an icon for the navigation, that builds its own widgets.

Derive from it and add the widgets in build(); PageNavigator calls it once the page is on the screen (so it already has its theme and bounds):

class ClockPage : public Page<RGB565> { public: ClockPage() : Page("Clock", drawClockIcon) {} void build() override { addChild(time_); ... } bool tick(uint32_t nowMs) override { ... return true; } // redraw };
