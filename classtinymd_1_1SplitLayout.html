Detailed Description

Splits a container into two panes (master/detail, nav/content).

Not a widget - see GridLayout.h for the rationale.

SplitLayout split(Bounds(0, 56, 320, 400), LayoutAxis::Horizontal, 96); nav.bounds = split.firstRect(); content.bounds = split.secondRect();

The first pane gets firstSize pixels (along axis); the second pane gets the remainder minus the gutter. Use ratio() instead of a fixed pixel size to split proportionally (e.g. 0.3f for a 30/70 split).
