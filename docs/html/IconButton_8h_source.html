13/// Signature every Draw/Icons.h glyph function matches: draw `color`, with
14/// stroke width `thickness`, into `bounds` on `target`. A function pointer's
15/// type reflects every declared parameter regardless of default arguments,

21/// kStandard is a plain flat tap target (the original IconButton look - app
22/// bar/toolbar icons). kFilled/kTonal add a colored, elevated circular
23/// background - for a dedicated Floating Action Button (elevation shadow,
24/// pill "extended" form with a label) see Fab.h's FloatingActionButton/FAB
25/// instead; this variant remains handy for a smaller status-dependent
26/// circular button paired with setColorOverride() (a play/stop control
27/// that's green or red, say).
28enum class IconButtonVariant { kStandard, kFilled, kTonal };
