15 *
16 * The first pane gets `firstSize` pixels (along `axis`); the second pane
17 * gets the remainder minus the gutter. Use ratio() instead of a fixed pixel
18 * size to split proportionally (e.g. 0.3f for a 30/70 split).
19 */
