7/// Clamps a signed widget-layout coordinate to a non-negative pixel index
8/// before it's passed into one of TinyGPU's size_t-based drawing calls.
9/// Needed because Bounds (this file) is deliberately signed while ISurface
10/// drawing calls take size_t - passing a negative value straight through
11/// would silently wrap to a huge unsigned value instead of clipping.
12inline size_t toPx(int32_t v) { return v < 0 ? 0 : static_cast<size_t>(v); }
