Detailed Description

template<typename RGB_T = TINYMD_DEFAULT_RGB_T>
class tinymd::RadioGroup< RGB_T >

Coordinates a set of RadioButtons so selecting one deselects the rest. Not itself a Widget - each RadioButton must still be added to the Screen individually, e.g.:

RadioGroup<RGB565> group; group.onChange = [](int index) { ... }; for (auto& button : buttons) { screen.addWidget(button); group.addButton(button); }
