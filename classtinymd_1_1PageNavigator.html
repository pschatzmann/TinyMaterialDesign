Detailed Description

template<typename RGB_T = TINYMD_DEFAULT_RGB_T>
class tinymd::PageNavigator< RGB_T >

Connects Pages with a NavigationBar: one destination per page, only the selected page is visible. All pages share the same bounds, so the screen itself never scrolls; each page scrolls on its own.

NavigationBar<RGB565> nav(Bounds(0, 264, 240, 56)); PageNavigator<RGB565> pages(app.screen(), nav); pages.addPage(clockPage); pages.addPage(settingsPage); pages.begin(Bounds(0, 40, 240, 224)); // adds nav + pages, builds them // loop(): if (pages.tick(millis())) app.screen().invalidate();
