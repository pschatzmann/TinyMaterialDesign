Detailed Description

template<typename RGB_T = TINYMD_DEFAULT_RGB_T>
class tinymd::WifiLoginPage< RGB_T >

WiFi selection and login as a Page: the state of the connection, SSID and password (masked, "Show password"), Connect / Scan, the networks of the scan (tap one to select it: open networks connect at once, for secured ones the keyboard opens for the password) and "Continue without WiFi".

The WiFi itself is a WifiControl: Esp32Wifi (Wifi/WifiEsp32.h) on the ESP32, SimulatedWifi on the desktop. Show the page on its own, or add it to a PageNavigator; call tick() regularly while it is shown (the PageNavigator does that) - it polls the scan and the connection and returns true when the page must be redrawn.

Keyboard<RGB565> keyboard(Bounds(0, 150, 240, 170)); WifiLoginPage<RGB565> login(keyboard); Esp32Wifi wifi;

void setup() { app.begin(); wifi.begin(); login.setWifi(&wifi); login.bounds = Bounds(0, 40, 240, 280); app.screen().addWidget(login); login.build(); login.onShow(); app.screen().addFixedWidget(keyboard); login.onDone = []() { ... }; // connected (startup) or skipped } void loop() { if (login.tick(millis())) app.screen().invalidate(); app.update(); }
