Detailed Description

template<typename RGB_T = TINYMD_DEFAULT_RGB_T>
class tinymd::StatTile< RGB_T >

A small tile with one value: a caption at the top, the value in an accent color and an optional unit / sub text - for dashboards and KPIs.

StatTile<RGB565> rate(Bounds(8, 40, 72, 46), "RATE", "s/day"); rate.setValue("+4.2"); rate.setAccent(colorFromHex<RGB565>(0x10B981));

The value is drawn in the title font and falls back to the body and label fonts if it does not fit. Outlined (default, on the page) or tonal (filled with surfaceVariant, e.g. inside a Card).
