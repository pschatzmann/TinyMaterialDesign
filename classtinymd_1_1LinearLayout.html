Detailed Description

Computes equal- or weighted-split rects along one axis of a container.

Not a widget - see GridLayout.h for the rationale. Use it before constructing/positioning widgets:

LinearLayout row(Bounds(16, 56, 308, 48), LayoutAxis::Horizontal); button1.bounds = row.itemRect(0, 3); button2.bounds = row.itemRect(1, 3); button3.bounds = row.itemRect(2, 3);

By default all count items split the container equally (minus spacing gutters). Pass per-item weights via itemRect(index, weights, count) to give some items more of the remaining space than others (weights are relative, not required to sum to 1).
