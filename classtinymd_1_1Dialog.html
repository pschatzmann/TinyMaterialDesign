Detailed Description

template<typename RGB_T = TINYMD_DEFAULT_RGB_T>
class tinymd::Dialog< RGB_T >

Modal alert dialog: full-screen scrim + centered card + title + wrapped message + action widgets (typically Button).

Show it with Screen::presentDialog(dialog); while presented, Screen routes every gesture to the dialog first. Actions (usually Button) are not owned by Dialog - position each one's bounds (actionRect() suggests a spot), add it with addAction(), and wire its onClick to call screen.dismissDialog() itself.

Alternative to addAction(): setActionProvider(count, at) switches to callback-driven actions instead - see Container.h's class comment for the same pattern (at(index) returns a Widget reference, typically from a small reused pool). Not usually needed for a dialog's handful of actions, but available for consistency.
