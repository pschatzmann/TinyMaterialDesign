Detailed Description

template<typename RGB_T = TINYMD_DEFAULT_RGB_T>
class tinymd::ListItem< RGB_T >

List row after the Material 3 list spec: a leading avatar or icon, a headline, an optional supporting text, a trailing text or icon, and an optional divider. Selected rows draw as a filled pill (the navigation-drawer look). Everything beyond the headline is opt-in, so a plain ListItem looks as before.

ListItem<RGB565> row(Bounds(0, y, 240, ListItem<RGB565>::kOneLineHeight), "Quarterly report"); row.setSupportingText("Alice <alice@example.com>"); // two-line item row.setLeadingText("A"); // 40 dp avatar with a letter row.setTrailingText("2 files"); // label on the right row.setDivider(true); // divider at the bottom edge

Sizes (dp, the same as px here): one-line item 56, two-line item 72, avatar 40, icon 24, dividers 1 with an inset of 16 from the text.
