Detailed Description

Grid with explicit, independently-sized column widths and row heights.

Not a widget - see GridLayout.h for the rationale. GridLayout assumes uniform cells and computes the column count for you; TableLayout is for dashboards mixing wide/narrow columns or short/tall rows, where you supply the sizes explicitly:

int32_t colW[] = {120, 80, 80}; int32_t rowH[] = {48, 96}; TableLayout table(Bounds(16, 56, 280, 200), colW, 3, rowH, 2); cell.bounds = table.cellRect(row, col);
